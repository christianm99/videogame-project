ABOUT THE PROJECT

BUILT FOR GAMERS.

Pixel Vault is a frontend development project built with HTML, CSS, and JavaScript. Game information is fetched dynamically from the RAWG API, then displayed and sorted using JavaScript.

The project demonstrates API fetching, search, sorting, dynamic rendering, loading states, and responsive web design.
